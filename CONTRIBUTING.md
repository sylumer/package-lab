that the additional attribution and provenance terms in [LINEAGE-AND-ATTRIBUTION.md](LINEAGE-AND-ATTRIBUTION.md) apply

Say so in the pull request ("I agree to the terms in CONTRIBUTING.md") so the agreement is on record.

Before opening a pull request, run `make test`. See [docs/developer-guide.md](docs/developer-guide.md) for how the code
fits together.
