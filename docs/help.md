# Package Lab help

Help for using the desktop app: what each part of the window does, and how to do each task. To *learn* Package Lab
step by step, from SCORM basics to expert diagnosis, open the **User Guide** instead (**Help › User Guide**, ⇧⌘G).

These pages cover the desktop app. The [web interface](web.md) is the same app in a browser, with an extra **Live** view. Each page is one task. New here? Start with [Getting started](help/getting-started.md).

- [Getting started](help/getting-started.md): install, open a package, run it, read the verdict.
- [Reading a run](help/reading-a-run.md): findings, milestones, boot path, timeline, reading the code, and a method for a package that doesn't work.
- [Run settings](help/run-settings.md): the inspector's Settings, group by group: LMS and profiles, browser and device, recording, advanced.
- [Views](help/views.md): every view, in sidebar order.
- [Macros and test saving](help/macros.md): test saving, recording macros, waits and the window size.
- [Changing and exporting](help/changing-and-exporting.md): changed files, pins and answers, corrected packages, reports, saved runs, comparing packages.
- [Experiments and servers](help/experiments-and-servers.md): experiments, working copies, server needs, why it stalled, drill-down, tracing.
- [cmi5, Tin Can and authoring tools](help/other-formats.md): the two xAPI formats, their xAPI view, and the authoring tool checks.

Every command and flag is in the [command line reference](cli.md). The [recipes](recipes.md) and [findings](findings.md) are separate.
