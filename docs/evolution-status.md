# Evolution status

## Summary

Phase 0 done: `test/ui.js` drives the real app through Playwright's Electron driver (`npm run test:ui`, also in `--slow`); slow suite passed and merged into main.

Phase 1 done: macro format 2 (window size, wait steps, a player on one clock), clicks tied to the element clicked with a position fallback, and a Record button in the desktop app. Each took one review round; the slow suite passed and main was fast-forwarded to b2eb223. Phase 2 done: a Mac toolbar with the system accent and hand-drawn icons, run settings in a right-hand inspector with a summary chip, views grouped in the sidebar, a verdict banner on Findings, and drop-to-open with one-line tooltips. Each took one review round. The slow suite passed on the final E2.5 tree (run by its builder under the lock). From E2.5 on, the plan runs in lanes (see evolution-plan.md, "Parallel lanes"); lane C needed no change.

Phase 3 done (lane B, in the docs worktree): the user guide split into pages with a link check, search and page contents in the docs panel with ⓘ context help, screenshots made by `npm run screenshots` and shown in the panel, and an Appearance setting (System, Light or Dark). Each took one review round and was merged into evolve with `--no-ff`; the slow suite passed on the final merge (96f5321). Phase 4 done (lane A): the Live view in the desktop app with page coordinates (two review rounds; round 2 fixed two flaky slow-suite timings that predate it), and the macro editor with named macros per package (one review round). The slow suite passed on d8da563 and again on 96f5321; main was fast-forwarded to the Phase 3 and 4 tree. Known flaky: `alfred fix: the copies are written next to the original` failed now and then across several runs and passed on rerun.

Note: the Phase 6 plan amendment ("Add Phase 6: a first Windows build") landed in the working tree while E3.1's merge was being staged, so it is part of merge commit 8dc83cf rather than a commit of its own. History wasn't rewritten, because the docs worktree had already moved to that commit.
